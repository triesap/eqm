Purpose and exact behavior changed:
The production `check` command previously evaluated binding artifacts against the
target's shipped output root only (`evaluate_structure`), even though binding
conversion and graph authority already own declared shared component roots. It now
reads the checked graph's exact per-target ownership closure via the new pure
`WorkspaceGraph::owned_roots` (output root plus the transitive declared
`source_components` closure) and evaluates with
`evaluate_structure_with_roots`. Target `depends_on` never contributes another
target's roots. No arbitrary caller-supplied root list is accepted, and
confinement is not widened: undeclared and escaped paths still fail at the real
loading/conversion boundary; forbidden symlinks still fail structurally. v1
behavior is preserved because a v1 target has no declared components and its
closure is exactly its output root.

Spec/API/schema/DB/authority impact:
Additive pure domain query and an internal CLI wiring change. No schema, digest
or wire change.
