## Changes

- Moved `FinalizedWorkspaceGraph` from `eqm_domain` to `eqm_engine` with a
  crate-private constructor used only after resolution, fragment expansion and
  post-expansion invariant validation. Removed the public `from_engine` bypass;
  no alias remains. Pure projections now take `&WorkspaceGraph` as data.
- Removed the public `Default` derive on `RequiredUniverse`; it can only be
  produced by `derive_required_universe` from the checked graph, exact
  selection, applicability context and release context.
- Consumed `evaluate_participation` per exact requirement/target coordinate,
  preserving no-rule-Unknown and ambiguity-error. Explicit false is visible
  N/A; unknown participation is non-authorizing. A graph with no participation
  authority (v1 cannot carry the axis) fans out on applicability alone.
- `UnresolvedCoordinate` now retains the exact subject, selected profiles and
  release context instead of a requirement-only marker.
- `evaluate_complete_target_conformance` requires a facet status for every
  participating target, provider and target-set coordinate and treats an
  unknown applicability/participation coordinate as non-conformant, so an
  omitted or unresolved coordinate cannot yield Conformant.
- The release command evaluates statuses for every participating coordinate and
  matches target-set evidence through its member targets.
- Added the synthetic end-to-end evidence spec the release fixture needs for a
  genuinely complete pass; regenerated the dependent reviewed goldens.
