duplicate-free target-set subjects, and synthetic evidence helpers for counts,
attempts, execution payloads, profile selections, and manual reviews. Every
helper delegates validation to the same domain constructors used in production,
returns a sanitized `FixtureError`, and never mints or raises trust. The
`eqm_engine` integration-test support now consumes the shared injected clock.

`eqm_test_support` so it can be a dev-dependency of `eqm_engine` without a
dependency cycle; `eqm_test_support` remains `publish = false`.
Spec/API/schema/DB/authority impact: test-only crate surface. No production
schema, DTO, wire or storage change. `Cargo.lock` updated intentionally for the
dependency-graph change; all subsequent checks ran `--locked`.
