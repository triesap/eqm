# P04-R3 — complete shared exact request preparation

**Scope:** `refactor: centralize exact selection request preparation`.
Owns RF74, RF76 and RF77, with the remaining S044 shared-preparation work.

## Changes

- Added the typed `PolicySelectionRequest`, `PolicyReference` and
  `ProfileSelection` application inputs plus `resolve_selection_request`, which
  resolves exact policy/profile revisions, rejects ambiguity and missing
  authority, enforces policy profile membership and rejects duplicate profile
  selections entirely inside the shared application layer.
- Added `prepare_obligations_from_request`, which resolves a typed request and
  then prepares under the explicit mode, never supplying a development default.
- Rewrote the CLI adapter to parse only transport syntax into the typed input
  and delegate all authority lookup and revision resolution to the application;
  removed the CLI-local resolver helpers.
- Updated the CLI help and `docs/cli.md` for `--policy <ID[@REVISION]>` and
  `--profile <ID[@REVISION][=DIM:VALUE,...]>`, and documented that these are
  unverified candidate inputs that never replace protected authority.
- RF77: repaired the unresolved `clean` rustdoc link in application source
  observations and the private-item link in the protocol positive unsigned
  schema, without changing numeric or source semantics.
- RF76: reconciled public progress and reports, recorded the P04-R2 repair
  commit and separated implemented, locally verified and independently accepted
  states.
