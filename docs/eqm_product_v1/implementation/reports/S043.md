Purpose and exact behavior changed:
The public schema surface is now parity-checked against the model. A real Draft
2020-12 validator runs on representative provider, cohort and semantic-graph
documents and independently authored one-axis negative mutations (missing
fields, wrong types, unknown members, invalid graph-backed configuration on an
authored cohort), and the committed provider/cohort/semantic-graph/
comparison-context schema paths and exact `$id`s are asserted. The standard
schema-URI parity scan now also covers the synthetic asymmetric fixture, so
every authored schema URI in the public fixtures resolves to a committed
schema.

The exact-subject separation control proves that changing only the
source/build/artifact axes moves the `SubjectManifestDigest` while the shared
`ComparisonContextDigest` and the target configuration identity stay unchanged,
and that both distinct subjects remain comparison-eligible under the one shared
context. This closes the S043 requirement that exact subject changes be
demonstrated separately from shared comparison identity and target
configuration. Public documentation records the v2 participation/scenario/
provider/cohort kinds and the new graph collections.
