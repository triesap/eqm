Purpose and exact behavior changed:
The generated Draft 2020-12 schemas now express the owning domain/ADR-0013 value
contracts that were previously only enforced by readers:

- Manifest authored v2: exact `workspace`, `scenario`, `participation`,
  `provider` and `cohort` markers; `provider`/`scenario`/`participation`/
  `source-component` dotted-ID vocabulary and bounds; single-segment
  occurrence/dimension/symbolic IDs; role/platform/framework extensible IDs;
  `owner://(team|role)/…` owner vocabulary with `uniqueItems`; SHA-256 digest
  text; 40-or-64 lowercase-hex source commits; canonical HTTPS repository
  identity; positive `revision` (minimum 1); nonempty assignments/targets;
  exactly-one target/provider configuration claim per cohort assignment; and
  exactly-one tagged scenario subject.
- Protocol graph/comparison members: the same identifier/digest/owner/repository
  forms; positive authority revisions over the canonical `WireUint` range; a
  nonempty selected-profile set and nonempty profile dimensions/values; bounded
  title (1..=160) and description (1..=4096); exact applicability operator
  vocabulary (`eq|ne`, `in|not_in`); nonempty `all`/`any` operands; and a closed
  recursive extension union (`additionalProperties: false` per tagged branch).
- `CohortAssignmentV2Dto` carries an `allOf` exactly-one constraint in both the
  authored manifest schema and the graph schema; the checked readers retain the
  authoritative semantic/byte validation.

Non-schema-expressible layers remain explicit: UTF-8 byte bounds, NFC,
extension depth/node limits, raw duplicate members and normalized logical-key
collisions stay in the owning reader/domain; exactly-one presence is
schema-expressible and is enforced in schema. Development-optional build/source
axes are not universally required; completeness remains the consuming mode's
obligation. v1 schemas and bytes are unchanged; no `additionalProperties`
fallback was broadened and no generated JSON was hand-edited.

Spec/API/schema/DB/authority impact:

changed and all v1 schema files are byte-identical.
