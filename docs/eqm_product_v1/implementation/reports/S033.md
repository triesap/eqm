## Scope

DEV-009 requires a shared artifact to be valid only through explicit declared
source-component ownership, not by lying under one output root, while wrong
targets and undeclared or escaped paths stay blocking.

## Representation

- `crates/eqm_manifest/src/conversion.rs`: `artifact` now accepts the target's
  complete declared root set. `convert_binding` keeps its v1 signature and uses
  the single output root; the new `convert_binding_with_roots` uses the target's
  output root plus every declared shared component root. A path inside a declared
  component admits; a path outside every owned root still fails with
  `artifacts.path`.
- `crates/eqm_manifest/src/loader.rs` builds each target's ownership roots from
  its output root plus the declared source components reachable through their
  dependency closure, then converts bindings through that ownership. The
  redundant per-target root map is removed.
- `crates/eqm_engine/src/structure.rs`: the new `evaluate_structure_with_roots`
  evaluates artifacts and symlink resolutions against the target's complete
  declared source ownership; `evaluate_structure` delegates with the single
  output root, so existing callers are unchanged. An unrelated path still reports
  `OutsideTargetRoot`.

No source content is read, no filesystem canonicalization is added, and no
schema or wire change is introduced.
