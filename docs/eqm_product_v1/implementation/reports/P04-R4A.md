# P04-R4A — reject incomplete non-target release evidence (RF79)

**Scope:** `fix: reject incomplete non-target release evidence`.
Owns the focused RF79 release-matcher repair, preserving every prior
participation/selection edit and the 47 earlier numbered acceptances.

## Changes

- `evidence_coordinate_matches` now binds an ordinary evidence result only to the
  exact `ScopeSubject::Target` coordinate it was produced for. `Provider` and
  `TargetSet` (scenario/end-to-end) coordinates fail closed until their complete
  exact subject/configuration/participant/dependency authority is integrated by
  the later owning steps. The unrestricted-provider and any-member-target-set
  shortcuts are removed.
- `subject_participates` is unchanged, so non-target coordinates remain visible
  in the denominator and resolve to `Missing`/`Unknown`; they can never produce
  `Pass` or `Conditional`. This deliberately does not implement the complete
  non-target representation allocated to S052/S054/S059/S061/S073.
- Added real-ingress controls driven through `execute_with_authority`:
  `full_scope_signup_rejects_incomplete_non_target_evidence` (the authored
  signup fixture keeps its end-to-end target set and is non-authorizing),
  `single_member_target_set_rejects_ordinary_target_evidence` (a one-member
  target set still rejects ordinary target evidence),
  `provider_scope_rejects_ordinary_target_evidence` (a declared provider
  requirement rejects ordinary target evidence), and
  `each_target_only_synthetic_control_passes_supported_scope` (a separate,
  explicitly authored each-target-only workspace passes under explicit synthetic
  authority and asserts it carries no non-target scope).
- The fixture helper `release_fixture` now composes an explicit authored
  transform (`each_target_only`, `single_member_target_set`,
  `wrong_provider_scope`) over a copy of the signup fixture. The authored
  full-scope fixture on disk is never modified and no requirement or evidence
  coordinate is deleted from it.
- Retained the preserved partial participation/selection, RF75/RF78/RF81/RF82
  and planning edits as partial dispositions. They are not closed here.
