`prepare`). The CLI now maps its `GlobalOptions`/`CommandName` envelope into the
application request and re-exports the prepared types; MCP adaptation stays in
the CLI as a free `mcp_session` function rather than a method on the shared
type. Loading semantics, the finalized graph, source map, workspace digest and
CLI behavior are unchanged; no reload or re-derivation happens across the MCP
boundary.
Spec/API/schema/DB/authority impact: internal module ownership moved across the
application boundary. No user-facing CLI grammar, schema, DTO, wire or storage
change. `Cargo.lock` updated intentionally for the new CLI dependency; checks
ran `--locked`.
