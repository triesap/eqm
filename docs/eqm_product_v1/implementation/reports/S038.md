## Scope

DEV-009 allocates exact subject assignments keyed by occurrence, retaining
separate repository, source commit, immutable source/component content, target or
provider configuration, build ID and artifact identities. Absence is typed and
allowed only for declared development context; a target digest alone never
satisfies a missing source or build axis.

## Representation

- `crates/eqm_domain/src/subject_manifest.rs` (new): `SubjectAssignment` keeps
  every axis separate and requires exactly one of the target/provider
  configuration identities. `is_complete` requires source content, build ID and
  artifact digest. `SubjectManifest` keys assignments by unique occurrence and
  `require_complete` rejects any incomplete assignment for trusted use.
- `crates/eqm_domain/src/digest.rs` adds the allocated
  `eqm:v2:subject-manifest` domain and `SubjectManifestDigest`.
- `crates/eqm_protocol/src/v2.rs` adds strict `SubjectManifestV2Dto` and
  `SubjectManifestEntryV2Dto` with omitted-wire absence, and validates the exact
  schema, typed identifiers and exactly-one configuration authority.
- `crates/eqm_domain/src/schema.rs` and `crates/eqm_protocol/src/schema.rs` add
  `SchemaKind::SubjectManifest` and `SUBJECT_MANIFEST_SCHEMA_V2`; the protocol
  generator emits `schemas/v2/protocol/subject-manifest.schema.json`.

## Tests added

- `crates/eqm_domain/tests/subject_manifest.rs`: complete target subject passes
  trusted completeness, a target digest alone never satisfies missing
  source/build, configuration-authority and duplicate-occurrence reject, empty
  rejects.
- `crates/eqm_protocol/tests/subject_manifest.rs`: strict round-trip with omitted
