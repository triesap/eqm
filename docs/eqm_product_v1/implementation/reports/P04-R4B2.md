# P04-R4B2 — protected release preparation

The application now requires an independently supplied AuthorityProvider for
protected obligation preparation. Candidate syntax/type validation grants no
authority. Exact policy/profile revisions and all dimension assignments are
validated before authority loading. The provider is loaded once, complete graph
definitions must match conservatively, and the returned selection/universe
borrows that protected graph. Later baseline-change comparison remains S129.

The actual release consumer uses Release mode, the validated immutable record
digest, and the one captured evaluation time; it fixes the denominator before
reading evidence. Missing protected authority returns structured Unknown/exit 7,
while missing/invalid selections and graph mismatch remain typed errors. The
development-universe helper is removed. Test-only graph authority is distinct
from signing-only trust and is inaccessible to production configuration.

Mandatory evidence, record and runtime trust conclusions are all required before
computing minimum trust. An absent conclusion can no longer vanish through
optional iteration. Public usage and renderer inputs use exact selections.
