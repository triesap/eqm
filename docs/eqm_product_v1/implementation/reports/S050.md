Purpose and exact behavior changed:
An empty required release scope (no release facets and no exposure comparisons)
previously fell through to `Pass`, a vacuous authorization by absence. It now
returns `Unknown` unless the caller carries explicit protected permission
(`empty_scope_authorized`), which defaults to `false` and is never derived from
defaults. A required cohort with fewer than two members now returns the new
`EquivalenceStatus::NoMeaningfulComparison` instead of `Equivalent`, so a
one-member cohort cannot support a cross-target equivalence claim. Local
inspection still returns full reports. No wire member, generated schema byte,
dependency or `Cargo.lock` entry changed.
