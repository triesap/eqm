Purpose and exact behavior changed:
The numeric boundary helpers in the protocol corpus reproduced owning range
predicates instead of calling the owning constructors. This checkpoint replaces
each helper with the genuine constructor decision: `PositiveCount::new` for
counts, a separate `Revision::new` for revisions, `DurationMillis::new` for
unbounded durations, `RunnerLimits::new(DurationMillis, PositiveCount::ONE,
None)` with valid other limits for the positive runner timeout, and a checked
`u32` conversion before `PositiveDays::new`. The normalized-text corpus now
covers every forbidden C0/C1 scalar (U+0000..U+001F except LF/TAB, and
U+007F..U+009F) both embedded between other characters and trailing, plus the
allowed LF/TAB controls, empty text and each carrier's exact ASCII byte maximum,
just-under and over-maximum. No production scalar rule, wire member, generated
schema byte, dependency or `Cargo.lock` entry changed.
