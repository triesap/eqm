JSON Schema's integer type includes numbers with no fractional value; original
lexical spelling is outside that assertion. Thus schema acceptance of an
integral value written as 1e3 is not itself a schema bug. The existing test's
claim of token-level equivalence is the defect. See the normative
[validation definition](https://json-schema.org/draft/2020-12/json-schema-validation#section-6.1.1).
DEV-003 explicitly separates those layers without weakening canonical input.
