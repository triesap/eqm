## Application and consumer changes

Application `structure` prepares the complete graph's unique artifact paths and
binding reports before filters, using the finalized target source-root closures.
Its explicit read-only observer receives independently inspected path/kind/root,
never authored roles or a binding. Unavailable/failed/foreign roles are Unknown;
independently observed empty/mismatching roles are failures. No observer is
configured implicitly. The CLI consumes the prepared report instead of copying
artifact roles into its own filesystem view, and preserves blocking Unknown.
Observations remain available beside reports for provenance; they do not grant
protected release trust or import producer verified flags.

Inspection checks all path components without following symlink ancestors or
forbidden leaf symlinks, classifies non-regular kinds, confines canonical regular
paths and detects metadata/path changes around an observer call. Actual NotFound
is distinct from inspection failure. Above 100000 unique paths preparation rejects
rather than truncating. These pathname checks do not prove immutable race-safe
acquisition; no artifact payload is opened/executed. Stronger acquisition/storage
and trust gates remain with their owning steps. Frozen schemas and dependencies
are unchanged.
