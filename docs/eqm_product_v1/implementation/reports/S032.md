## Scope

DEV-009 permits two outputs to share a declared source component without
weakening repository containment. The loader must distinguish a target's
shipped output identity from shared source roots, keep portable output collision
checks, and reject ambiguous undeclared overlaps or path escapes.

## Representation

`crates/eqm_manifest/src/loader.rs`:

- The existing target-output portable collision check is retained: two targets
  with colliding output roots still reject (`DuplicateTargetRoot`). Declaring a
  shared component does not exempt or rename the output identity.
- `roots_overlap` performs repository-relative segment containment.
- `validate_shared_source_overlaps`:
  - two distinct source components whose roots overlap are accepted only when
    one reaches the other through the declared dependency closure; otherwise the
    overlap is ambiguous and rejects as `AmbiguousSourceOverlap`;
  - a target whose output root overlaps a source component it does not declare
    rejects as `UndeclaredSourceOverlap`.
- Escaped or absolute component roots already fail in `RepoPath::new` and remain
  a `WorkspaceTarget` error; no filesystem canonicalization is introduced.
- The check runs after the target/component tables are built and is a no-op for
  v1 workspaces, which carry no source components.
