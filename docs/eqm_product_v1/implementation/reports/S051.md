Purpose and exact behavior changed:
Obligation strength previously composed every matching policy rule for a
requirement and applied that single strength to every facet of the requirement,
so one facet's trust/count/age constraint leaked onto an unrelated facet of the
same requirement. Strength is now composed per facet from only the rules that
declare that facet. Requirement-level rule selection is unchanged; the set of
facets and the per-facet minimum trust/count/age are now correct. No wire
member, generated schema byte, dependency or `Cargo.lock` entry changed.
