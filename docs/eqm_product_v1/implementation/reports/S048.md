Purpose and exact behavior changed:
Requirements whose applicability is explicitly false or unknown previously
disappeared from derivation output, so a skipped requirement could vanish from
completeness. Derivation now records a typed `UnresolvedCoordinate` (owning
unit, fully qualified requirement, and `NotApplicable` / `UnknownApplicability`
/ `UnmatchedPolicy` reason) for every visible requirement that yields no
obligation. `ObligationDerivation` exposes these alongside its obligations, and
`RequiredUniverse` carries the same unresolved set so the pre-evidence
denominator includes unknown and justified not-applicable coordinates rather
than shrinking. The existing `unknown_applicability` and `unmatched_warnings`
sets are retained. No selection rule, wire member, schema byte, dependency or
`Cargo.lock` changed.
