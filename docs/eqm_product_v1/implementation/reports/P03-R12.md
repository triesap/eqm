## Locally expressible rules now enforced

| Owning type | Owning rule | Schema expression |
|---|---|---|
| `Journey::new` | surfaces nonempty and exact-unique, authored order preserved | `NonEmptyOrderedList<SurfaceIdText>` (`minItems` 1, `uniqueItems`; never sorts) |
| `Surface::new` | at least one direct requirement **or** fragment origin | `anyOf` of `requirements` `minItems` 1 / `fragment_origins` `minItems` 1 |
| `Requirement::new` | `provider` present exactly when `scope = shared_provider` | `allOf` `if`/`then` on `scope`/`provider` |
| `PolicySelector::new` | at least one axis populated | `anyOf` of the five axis `required` members |
| `WaiverPolicy::new` | `allowed` exactly when `maximum_days` is present | `allOf` `if`/`then` on `allowed`/`maximum_days` |
| `EnvironmentBinding::new` + conversion | `value` present exactly for `literal`; fixed-name sources pin the name; `literal` accepts any name | `allOf` `if`/`then` on `source`/`value` and `source`/`name` |
| `RunnerDefinition::new` | a `local` backend claims no guarantees | `allOf` `if backend = local` then `guarantees` `maxItems` 0 |
| `Artifact::new` | user-visible roles require a surface/symbol/selector locator | `allOf` `if role in {entrypoint,view,route,component}` then `anyOf` locator `required` |
| `EvidenceSpecification::new` | executable kinds require a runner; non-executables forbid one; only countable kinds may carry `minimum_count`; the selector variant must match the kind (executables require a selector, `manual_review` forbids one) | `allOf` `if`/`then` on `kind`/`runner`, `kind`/`minimum_count` and `kind`/`selector.kind` |

The `release_record` kind requires the owning `release` evidence-selector
variant. The graph projection already emits it (`evidence_spec_v2`) and the
authored `EvidenceSelectorDto` already supports it, but the graph DTO omitted it.
Since a faithful `kind`/`selector` combination cannot be expressed without the
existing owning variant, `EvidenceSelectorV2Dto::Release { channel }` (closed
`ReleaseChannel` vocabulary) is added. No new product scope, parser policy or
digest semantics are introduced, and every previously valid document remains
valid.
