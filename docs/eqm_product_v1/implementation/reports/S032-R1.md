Purpose and exact behavior changed:
The loader previously accepted a source component overlapping a target root only
when the target named that component directly, while binding-root conversion
already used the full transitive `source_components` closure. A valid nested
ownership (target declares `shared.a`, which depends on `shared.b`, whose root
sits under the target root) was therefore rejected as undeclared. The loader now
computes one deterministic transitive component closure over the declared
component dependency graph and uses it for both the target/root overlap check and
binding-root ownership. Target `depends_on` edges never grant another target's
roots; only the target's own declared component closure does. Missing/cyclic/
duplicate/portable-output-root/escape/ambiguous checks are preserved: the
component/component overlap check still requires the complete overlap to be
explained by the same declared closure in either direction.

Spec/API/schema/DB/authority impact:
Internal loader refactor only. No public API, schema, digest or wire change; no
domain/engine boundary change.
