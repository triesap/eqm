## Approved decisions

- Required expected selections compose conjunctively. Alternatives require explicit protected groups and frozen authorized selection; no pass-driven substitution. Count distinct declared logical cases/observations at the obligation coordinate, never files, copies or retries.
- For otherwise valid eligible evidence: distinct required fail/pass cases are Failed; same-case failing/passing retry history is Unstable; contradictory same immutable attempt is Unknown. Missing/skipped/filtered/quarantined selections are non-success; timeout/cancellation is Unknown. Preserve all reasons and canonical precedence; Unknown/Unstable cannot be waived.
- Select current campaigns by explicit authorized manifests/relationships; do not choose the latest passing timestamp or poison a selected campaign with unrelated superseded history.
- Policy strengthening preserves the protected obligation universe and relevant per-facet constraints. Raising a minimum-level selection floor can weaken scope.
- Fragment requirements inherit the stronger source-fragment/destination-journey default. An absent risk inherits that value; an explicit lower value rejects. Validate after expansion and close unchecked finalized/prepared construction.
- Use an explicit new wire namespace for incompatible changes, preserve signed originals and reject unsupported versions. Do not reuse existing v1 identities or introduce implicit legacy readers. S006 chooses exact namespace/URI spelling and documents the transition after inspecting consumers and generators; newly discovered conflicting external obligations require an explicit disposition, not another request to approve the already accepted direction.
- Initial EQM execution/storage host target matrix: macOS arm64 and Linux x86_64. Windows is outside this initial promised matrix and must reject unsupported guarantees; adding Windows requires explicit scope and native evidence. Product desktop/mobile OS/SDK/device matrices are separate Q01/Q02 inputs. Host approval is a requirement to verify, not a claim that either lane already passed.
- Preserve canonical UTC nanosecond time and exact freshness arithmetic; explicit policy supplies age and skew. S006 finalizes integer ranges/decimal-string treatment, exact canonical time forms, null/absence, set/sequence and digest-domain vectors. No hidden five-minute skew or invented production policy values.
- Keep engineering ownership of exact API names, minimal reuse of existing command grammar, audited dependency/runtime selection and justified implementation boundaries. Prefer safe APIs; pure domain/engine remain unsafe-free.
- Initial deployment remains developer/CI tooling. Native embedding N001–N016 stays inactive. Release enforcement remains shadow/unconfigured until required evidence and separate activation authority exist.
