# ADR 0003: Typed Graph Domain Model

Status: approved

## Decision

Capabilities, journeys, surfaces, fragments, requirements, targets, bindings,
artifacts, exposure, policy, waivers, evidence, inventories, runtime facts, and
releases form a validated typed graph independent of source paths.

## Consequence

Source DTOs, semantic domain types, and public protocol DTOs remain distinct.
Graph identity comes from validated semantics, not file layout.
